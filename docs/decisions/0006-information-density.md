# D-006 界面先给要点，细节按需展开

- 状态：已采用（替代样机第1版的页面结构）
- 日期：2026-11-25
- 相关：方案 §5.3（概览层控制在一屏）、§6.1（首页先给自包含简报）、§6.7（视觉密度）

## 背景

研究负责人看过样机第1版后的反馈：页面太复杂、信息塞得太满、找不到重点。首页一眼看去全是文字；路线比较、大纲、决策与审阅、证据与成果、术语表、连接与能力都显得复杂。

第1版的问题在于把方案要求的每一项信息都直接摆在页面上：8个导航入口、每张卡片附带触发依据和来源、正文里每个对象ID都展开成长标题、比较表8行长文本。信息都对，但没有层次。

## 决定

1. **导航从8项减到4项**：概览、研究路线、待处理、资料。
   - 大纲并入“研究路线”，作为“图 / 列表”切换；路线比较是“研究路线”里的一个按钮。
   - 术语表并入“资料”的一个标签页。
   - 连接与能力放到顶栏的“正在执行”状态和“设置”菜单里。
2. **每页只放一个主问题**：
   - 概览：研究问题 + “已经知道 / 还不知道 / 正在做”三张卡 + 最多三件“需要你处理” + 最近四条变化。
   - 研究单元：默认只看“为什么做、已经知道、还不知道、下一步”；方法、实现、证据、历史放在标签页里；项目背景和局限放在“更多”里。
   - 待处理：每件事一句话说明 + 直接可点的选项；风险、依据和记录折叠。
   - 路线比较：每条路线一张卡（做法、完成率、支持、不利、成本），完整维度表折叠。
   - 资料：每项一行，点开看来源。
3. **正文中的来源引用改为小标签**（如“证据↗”“运行↗”），完整名称在悬停提示里，点击仍直达来源（C09 不变）；研究单元、路线、运行和约束仍显示名称。
4. **状态显示为“圆点 + 文字”**，去掉符号图标；颜色仍只作辅助。
5. 为此在样机扩展数据中增加了短文本：首页要点、变化的一句话说明、待关注事项的一句话说明与按钮文字、决定和候选的一句话说明、实验运行的关键结果、路线卡片内容（见 D-002 的扩展文件）。

## 没有改变的

方案的语义要求都保留，只是改为按需展开：审阅与采用分开、主张的适用条件、支持与反证、推断关联与精确来源、能力降级、从快照继续带上后来的反证、授权复用与撤销。自动化测试（30项）全部照旧通过。

## 暂时去掉的

- 研究单元页的“局部提问”输入框：样机不接模型，这个框只能显示为不可用，徒增干扰。接入模型时再加回。
- 首页的工作约定表格与完成条件清单：移到研究单元页（方法与实现、历史）中。

这些取舍需要在阶段A理解测试中验证：如果读者因为信息被折叠而漏掉关键限制，要把对应内容提回默认视图。
